# Portfolio - Thái Hà (Fullstack / Backend Developer)

Chào mừng bạn đến với kho lưu trữ mã nguồn trang Portfolio cá nhân của tôi. Đây là một trang web Single Page Application (SPA) hiện đại, đáp ứng (responsive), và được tối ưu hóa để giới thiệu lý lịch trích ngang, kinh nghiệm làm việc, kỹ năng lập trình và các dự án tôi đã thực hiện.

## 🚀 Tính năng nổi bật
- **Giao diện hiện đại (Modern UI/UX)**: Thiết kế tối giản hiện đại sử dụng Glassmorphism kết hợp màu sắc HSL hài hòa.
- **Chuyển đổi giao diện (Dark/Light Theme)**: Hỗ trợ người dùng thay đổi chế độ tối/sáng theo sở thích cá nhân, lưu trữ lựa chọn trong LocalStorage.
- **Hiệu ứng mượt mà**: Hiệu ứng gõ chữ (typing animation) động ở phần giới thiệu, cuộn mượt (smooth scrolling) và thanh điều hướng thông minh (Scrollspy).
- **Tương thích thiết bị (Responsive Design)**: Hiển thị hoàn hảo trên các thiết bị Mobile, Tablet, Desktop.
- **Tối ưu SEO**: Cấu trúc thẻ HTML chuẩn ngữ nghĩa (Semantic HTML), tốc độ tải trang nhanh và thân thiện với công cụ tìm kiếm.

## 🛠️ Công nghệ sử dụng
- **HTML5**: Định hình cấu trúc nội dung.
- **CSS3 (Vanilla)**: Thiết kế giao diện, bố cục Grid & Flexbox, và các hiệu ứng động.
- **JavaScript (Vanilla ES6+)**: Xử lý logic nghiệp vụ giao diện và hiệu ứng tương tác.
- **Boxicons**: Thư viện icons sắc nét, hiện đại.
- **Google Fonts**: Phông chữ Outfit và Inter sang trọng, dễ đọc.

## 📁 Cấu trúc thư mục
```text
portfolio/
├── index.html     # Cấu trúc nội dung trang web chính
├── style.css      # Định kiểu giao diện và hiệu ứng
├── script.js      # Logic hoạt động của giao diện
├── avatar.jpg     # Ảnh đại diện cá nhân
└── README.md      # Tài liệu giới thiệu dự án
```

## 💻 Cách chạy dự án dưới máy cục bộ
Để chạy và xem trực tiếp trang Portfolio trên máy tính cá nhân của bạn, chỉ cần mở trực tiếp file `index.html` bằng bất kỳ trình duyệt web nào, hoặc sử dụng tiện ích **Live Server** trong VS Code để tải lại tự động (hot reload).
